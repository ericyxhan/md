# Examples

## Golden path (quick test)
Use the sample inputs in [`test_inputs_7yae/`](../test_inputs_7yae/) to verify your MolDy deployment:

- Protein and ligand files are provided there.
- In the web UI: **New Job** → upload/select those files → choose the **Quick check** preset → run.
- In CLI: see the root [README.md](../README.md) pipeline section for `simulate.py --config ...`.

These files are intended for smoke testing (not for production science results).
